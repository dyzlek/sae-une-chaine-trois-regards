Le cristal-île

Le symbole de Terre commune. Une île low-poly coupée par la mer : au-dessus, la terre que les messages ont fait émerger ; en dessous, la racine, ce que la chaîne garde sans le montrer. Il est calculé depuis la chaîne, comme l'œuvre.

Dans l'en-tête de l'application, le symbole est recalculé à chaque bloc. Graine = 8 premiers caractères de l'id du dernier message (Mulberry32, comme l'œuvre). Versant filaire = message en prévision ; versant Brume = message masqué.

D'où il vient

Visit Nordkyn (Neue, 2010) : un cristal que la météo déforme chaque jour. Nous : un cristal que les messages déforment à chaque bloc. On garde les facettes et la lumière.

MIT Media Lab (TheGreenEyl, 2011) : une règle, des milliers de variantes. On garde l'idée, pas les aplats superposés.
