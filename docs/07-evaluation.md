# Évaluation

| Critère | Poids | Notation |
|---|---|---|
| Nœud | 25 % | binôme |
| Application | 20 % | binôme |
| Direction artistique | 20 % | binôme |
| Conception (S48) | 15 % | binôme (+ spec commune à six) |
| Conduite de projet | 10 % | **individuelle** |
| Oral | 10 % | **individuelle** |

## À savoir
- Conduite de projet et oral sont notés individuellement (20 % individuel).
- Un déséquilibre net dans un binôme peut conduire à individualiser la note.
- L'aide d'une IA pour coder est autorisée ; **à l'oral, chacun explique tout ce que son binôme a produit**.

## Conséquence pratique
- Tenir [journal.md](journal.md) à jour (preuve de conduite de projet).
- Répartir et relire le travail pour que chacun comprenne tout le code.
